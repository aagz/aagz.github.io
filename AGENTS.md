# Правила коммитов

- Коммиты создаются без строки `Co-authored-by`.
- Сообщение коммита имеет формат: `тип правки: текст коммита`.
- Текст сообщения коммита пишется на русском языке.
- Используй короткие типы: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`.
- Разделяй изменения на самостоятельные коммиты по логике: один коммит — одна связная задача.
